## Installation

via pip:

```shell
pip install git+https://github.com/nomutin/CNN.git
```

## Development

Need [uv](https://github.com/astral-sh/uv):

```shell
git clone https://github.com/nomutin/CNN.git && cd CNN
uv sync --extra dev
```
